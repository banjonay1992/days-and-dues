# Days & Dues website

Public product, pricing, support and legal pages for the iPhone app.

Live address: https://banjonay1992.github.io/days-and-dues/

## Edit and verify

Edit `content/*.html` for page content, `styles.css` for design, and `site.js` for the accessible screen tour. Shared layout and metadata are generated by `scripts/build.py` using Python 3.9 or later, with no dependencies.

```sh
python3 scripts/build.py
python3 -m unittest discover -s tests -v
python3 -m http.server 8766 --bind 127.0.0.1
```

Commit the generated HTML, sitemap and manifest alongside their source files. GitHub Pages publishes the root of `main`; `.nojekyll` keeps this a plain static site. The site needs no analytics, remote fonts, browser database, form service or third-party scripts.

## Release and pricing accuracy

`site.json` records the canonical URL, page metadata and `release_state`. The October 9, 2026 website describes iPhone version 3.0.0, which is awaiting Apple review and manual release. The existing App Store link may show the previous release. Remove the release notice and update corresponding page copy only once the new version is actually public. Screenshots contain example records.

The UK monthly subscription is £7.99. The separate one-time app trial provides 72 hours of Pro after eligible setup, without a card, subscription or automatic charge. Apple subscriptions renew once a user explicitly purchases one. Invoices are currently GBP and tax estimates follow UK sole-trader rules.

## Search and future domains

Every public page has a unique title and description, a self-referencing canonical URL, Open Graph and Twitter metadata, and structured data. `sitemap.xml` lists the nine indexable pages; `404.html` is excluded and has `noindex`. No ratings, testimonials or review data are invented.

No custom domain has been configured. When one is chosen, update `site.json`'s `url`, rebuild, set up that domain and its HTTPS hosting, and update redirects and App Store links to support/legal pages together. Keep established links working.

GitHub project Pages cannot set an HTTP 301. The legacy site uses immediate (zero-second) meta refresh plus canonical URLs and readable links to the corresponding new pages. Keep these redirects for old installed-app links.

Google only reads `robots.txt` at the **host root**, so the generated file under `/days-and-dues/` does not control crawling on the current shared GitHub Pages hostname. It is ready for a future dedicated domain. Sitemap discovery is also linked in the pages and footer. Search Console verification/sitemap submission has not been performed, and recrawling/indexing is controlled by search engines.
